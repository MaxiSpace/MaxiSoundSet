# مکسی سَوندسِت

[English](README.md)

مکسی سَوندسِت یک نرم‌افزار دسکتاپ ویندوز برای پردازش تطبیقی صدا و کنترل بلندی صدا است. این برنامه با Rust و Slint ساخته شده و نسخهٔ رسمی فعلی آن **v1.0.1** است.

## قابلیت‌ها

- انتخاب و پردازش دستگاه خروجی صدا.
- پردازش تطبیقی بلندی صدا، پروفایل‌ها، کنترل شدت و نرم‌سازی فرکانس‌های بالا.
- هدایت اختیاری صدای پردازش‌شده به کابل مجازی برای ضبط یا استریم.
- اجرای برنامه همراه ویندوز و، در صورت فعال‌بودن گزینه، ادامه‌دادن آخرین نشست صوتی فعال پس از ورود به ویندوز.
- رابط فارسی راست‌به‌چپ و انگلیسی چپ‌به‌راست.
- بررسی انتشار نسخه‌های جدید برنامه از GitHub در صفحۀ «دربارهٔ برنامه».

## نصب

فایل `MAXI-SOUNDSET-v1.0.1-Setup.exe` را از صفحۀ [Releases](../../releases) دانلود و اجرا کنید.

برنامه پس از نصب از پوشۀ نصب‌شده اجرا می‌شود. فایل‌های همراه فایل اجرایی را حذف نکنید.

## هدایت به کابل مجازی

هدایت به کابل مجازی اختیاری است. فقط زمانی آن را فعال کنید که بخواهید نرم‌افزار دیگری، مانند ابزار ضبط یا استریم، صدای پردازش‌شدۀ مکسی سَوندسِت را از یک دستگاه صوتی مجازی دریافت کند. پیش از استفاده، یک کابل صوتی مجازی سازگار را جداگانه نصب و تنظیم کنید.

## به‌روزرسانی

صفحۀ «دربارهٔ برنامه» انتشارهای GitHub را برای به‌روزرسانی خود برنامه بررسی می‌کند. بررسی اجزایی مانند در دسترس‌بودن کابل مجازی، مستقل از بررسی آپدیت برنامه است.

## ساخت از سورس

این پروژه برای ویندوز است. در پوشۀ `MaxiSoundSet-Rust` اسکریپت ساخت Release را اجرا کنید:

```powershell
.\Run-Beta2-Checks.ps1 -Action release
```
